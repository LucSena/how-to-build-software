# WCAG 2.2 Level A + AA Checklist

Every Level A and AA success criterion in WCAG 2.2 (W3C Recommendation, October 2023), paraphrased, with how to test it and the failure agents produce most often. **New in 2.2** is marked ★. 4.1.1 Parsing was removed in 2.2 and is not listed.

Legal context (as of 2026-09): the European Accessibility Act has applied since 2025-06-28 via EN 301 549, which currently references WCAG 2.1 AA (a revision aligned to 2.2 is expected); ADA case law and Section 508 reference WCAG 2.x AA. Building to 2.2 AA covers 2.1 AA.

## 1 Perceivable

| SC | Level | Requirement | How to test | Common failure |
|---|---|---|---|---|
| 1.1.1 Non-text Content | A | Text alternative for meaningful non-text content; decorative content hidden | Inspect `alt`, accessible names of icon buttons, SVG `role="img"` + title/label | `alt="image"`, missing `aria-label` on icon buttons, decorative SVG announced |
| 1.2.1 Audio-only / Video-only (prerecorded) | A | Transcript, or audio/text alternative | Check media has a transcript link | Podcast with no transcript |
| 1.2.2 Captions (prerecorded) | A | Captions for video with speech | Play with captions on | Autogenerated captions never reviewed |
| 1.2.3 Audio Description or Media Alternative | A | Visual-only info described or transcript | Watch without looking | Demo video relies on on-screen text only |
| 1.2.4 Captions (live) | AA | Live captions for live video | Check live player | Webinar without captions |
| 1.2.5 Audio Description (prerecorded) | AA | Audio description of important visuals | Listen without watching | Product tour with silent UI clicks |
| 1.3.1 Info and Relationships | A | Structure conveyed in markup | Headings outline, landmarks, table headers, label association (axe + manual) | Styled divs as headings, tables without `<th>`, unlabeled groups |
| 1.3.2 Meaningful Sequence | A | Reading order matches meaning | Read with a screen reader / disable CSS | CSS `order` or absolute positioning reorders content |
| 1.3.3 Sensory Characteristics | A | Instructions don't rely only on shape, position, sound | Read the copy | "Click the green button on the right" |
| 1.3.4 Orientation | AA | Works in portrait and landscape | Rotate device | Orientation locked without necessity |
| 1.3.5 Identify Input Purpose | AA | Personal-data fields expose purpose | Check `autocomplete` tokens | Name/email/address fields without `autocomplete` |
| 1.4.1 Use of Color | A | Color is not the only signal | Grayscale view | Error shown only by red border; links in body text without underline |
| 1.4.2 Audio Control | A | Auto-playing audio > 3 s can be paused/muted | Load page | Background video with sound |
| 1.4.3 Contrast (Minimum) | AA | Text 4.5:1; large text 3:1 (≥ 24 px, or ≥ 18.66 px bold) | Contrast checker on every state and theme | Muted gray text, placeholder text, text over images, dark theme secondary text |
| 1.4.4 Resize Text | AA | 200% text size without loss | Browser zoom 200% | Fixed-height containers clip text; `vw`-only font sizes |
| 1.4.5 Images of Text | AA | Real text instead of text baked into images | Inspect hero/banners | Headline as a PNG |
| 1.4.10 Reflow | AA | No 2-D scrolling at 320 CSS px width | 1280 px window at 400% zoom, or 320 px viewport | Fixed-width layouts, wide tables without their own scroll container |
| 1.4.11 Non-text Contrast | AA | UI component boundaries, states, meaningful graphics 3:1 | Check input borders, focus rings, icons, chart marks | Light gray input borders, faint focus rings, low-contrast toggles |
| 1.4.12 Text Spacing | AA | No loss with line-height 1.5, paragraph 2em, letter 0.12em, word 0.16em | Apply a text-spacing bookmarklet | Buttons with fixed height clip text |
| 1.4.13 Content on Hover or Focus | AA | Dismissible (Esc), hoverable, persistent | Hover tooltip, move onto it, press Esc | Tooltip vanishes when the pointer moves onto it |

## 2 Operable

| SC | Level | Requirement | How to test | Common failure |
|---|---|---|---|---|
| 2.1.1 Keyboard | A | All functionality operable by keyboard | Unplug mouse, complete every task | Div click handlers, drag-only reorder, hover-only menus |
| 2.1.2 No Keyboard Trap | A | Focus can always leave | Tab into embeds, widgets, modals; press Esc/Tab | Custom editor or iframe swallows Tab |
| 2.1.4 Character Key Shortcuts | A | Single-key shortcuts can be turned off, remapped, or only active on focus | Try typing in a field with shortcuts active | "j/k" shortcuts firing while dictating |
| 2.2.1 Timing Adjustable | A | Time limits can be turned off, adjusted, or extended (warn ≥ 20 s before) | Wait for session timeout | Silent logout; critical info only in a 3 s toast |
| 2.2.2 Pause, Stop, Hide | A | Moving/blinking/auto-updating content > 5 s can be paused | Look for carousels, marquees, loops | Auto-advancing carousel without pause |
| 2.3.1 Three Flashes or Below Threshold | A | Nothing flashes > 3 times per second | Review animations, video | Flashing error or celebration effect |
| 2.4.1 Bypass Blocks | A | Skip repeated content | First Tab shows a skip link; landmarks exist | No skip link, no `<main>` |
| 2.4.2 Page Titled | A | Descriptive, unique `<title>` | Check tab title on every route | SPA title never changes |
| 2.4.3 Focus Order | A | Order preserves meaning | Tab through | Positive `tabindex`; modal content focused after page content |
| 2.4.4 Link Purpose (In Context) | A | Link text plus context explains destination | List links in a screen reader rotor | "Click here", "Read more" ×10 |
| 2.4.5 Multiple Ways | AA | More than one way to find pages (nav, search, sitemap) | Check site structure | Deep pages only reachable via one path |
| 2.4.6 Headings and Labels | AA | Headings and labels describe topic/purpose | Read the headings list | Vague "Details" everywhere |
| 2.4.7 Focus Visible | AA | Visible keyboard focus | Tab through with a critical eye | `outline: none` without replacement |
| 2.4.11 Focus Not Obscured (Minimum) ★ | AA | Focused item not entirely hidden by author content | Tab with sticky header/footer, cookie banner, chat widget visible | Sticky header covers focused links after scroll |
| 2.5.1 Pointer Gestures | A | Multipoint/path gestures have single-pointer alternatives | Try without pinch/swipe | Map zoom only via pinch |
| 2.5.2 Pointer Cancellation | A | Activation on up-event; can abort by moving away | Press, drag off, release | Action fires on `mousedown`/`touchstart` (dropdown triggers are an accepted exception when reversible) |
| 2.5.3 Label in Name | A | Accessible name contains the visible label | Compare visible text with computed name | Button shows "Search", `aria-label="Find items"` |
| 2.5.4 Motion Actuation | A | Shake/tilt has a UI alternative and can be disabled | Look for device-motion features | Shake-to-undo only |
| 2.5.7 Dragging Movements ★ | AA | Drag actions achievable with single-pointer without dragging | Complete each drag task by clicking/tapping only | Kanban or sortable list with drag only |
| 2.5.8 Target Size (Minimum) ★ | AA | Targets ≥ 24×24 CSS px, or spacing so a 24 px circle on each doesn't overlap another; exceptions: inline text links, equivalent control elsewhere, UA-styled controls, essential | Measure small icons, pagination, close buttons | 16 px close "×", tightly packed icon toolbars |

## 3 Understandable

| SC | Level | Requirement | How to test | Common failure |
|---|---|---|---|---|
| 3.1.1 Language of Page | A | `<html lang>` set correctly | Inspect | Missing `lang`, or `lang="en"` on a localized page |
| 3.1.2 Language of Parts | AA | Passages in another language marked | Inspect quotes, names of languages in a switcher | Language switcher items read with the wrong pronunciation |
| 3.2.1 On Focus | A | Focus doesn't trigger a context change | Tab through | Focusing a field opens a new page or modal |
| 3.2.2 On Input | A | Changing a setting doesn't change context without warning | Change selects, radios | `<select>` that navigates immediately |
| 3.2.3 Consistent Navigation | AA | Repeated navigation in the same order | Compare pages | Menu order changes per page |
| 3.2.4 Consistent Identification | AA | Same function, same name/icon | Compare components | "Delete" vs "Remove" vs trash icon for the same action |
| 3.2.6 Consistent Help ★ | A | Help mechanisms in the same relative order across pages | Compare pages with help/contact | Chat link moves between header and footer |
| 3.3.1 Error Identification | A | Errors described in text and the field identified | Submit invalid form | Red border only |
| 3.3.2 Labels or Instructions | A | Labels/instructions where input is required | Inspect forms | Placeholder-only fields, format rules only in the error |
| 3.3.3 Error Suggestion | AA | Suggest a correction when known | Submit invalid values | "Invalid input" |
| 3.3.4 Error Prevention (Legal, Financial, Data) | AA | Submissions reversible, checked, or confirmed | Walk the purchase/delete flow | One-click irreversible payment with no review |
| 3.3.7 Redundant Entry ★ | A | Info entered earlier in the same process is prefilled or selectable | Walk multi-step flows | Re-typing the shipping address as billing |
| 3.3.8 Accessible Authentication (Minimum) ★ | AA | No cognitive function test (recall, transcription, puzzle) unless an alternative/mechanism exists; object recognition and personal content allowed at AA | Try password manager, paste into password and OTP fields | Paste blocked; OTP split into boxes that reject paste; text CAPTCHA only |

## 4 Robust

| SC | Level | Requirement | How to test | Common failure |
|---|---|---|---|---|
| 4.1.2 Name, Role, Value | A | Components expose name, role, state; changes are notified | Screen reader + accessibility tree inspector | Custom toggles without `aria-pressed`/`aria-checked`; `aria-expanded` not updated |
| 4.1.3 Status Messages | AA | Status messages announced without focus change | Trigger saves, searches, cart adds with a screen reader | "Added to cart" only visual; results count silent |

## Useful AAA targets

Not required for AA, but cheap and worth adopting as defaults:

| SC | Requirement | Why adopt |
|---|---|---|
| 2.4.13 Focus Appearance | Indicator at least as large as a 2 px perimeter, 3:1 change contrast | A concrete spec for the focus ring token |
| 2.5.5 Target Size (Enhanced) | 44×44 CSS px | Matches iOS/Android guidance; default for touch |
| 2.3.3 Animation from Interactions | Motion triggered by interaction can be disabled | Satisfied by a proper reduced-motion variant |
| 1.4.6 Contrast (Enhanced) | 7:1 / 4.5:1 | Good target for long-form reading |
| 2.4.12 Focus Not Obscured (Enhanced) | No part of the focused item hidden | Avoids partial covering by sticky bars |

## Mobile mapping

WCAG applies to native apps through EN 301 549 and WCAG2ICT. The practical translation:

| WCAG | iOS | Android |
|---|---|---|
| 1.1.1 / 4.1.2 | `accessibilityLabel`, traits, `accessibilityValue` | `contentDescription`, `Modifier.semantics`, `Role` |
| 1.4.4 Resize text | Dynamic Type text styles | `sp` units, font scale |
| 2.5.8 Target size | 44×44 pt | 48×48 dp |
| 2.4.3 Focus order | VoiceOver order via grouping/sort priority | `traversalIndex`, `isTraversalGroup` |
| 4.1.3 Status messages | `AccessibilityNotification.Announcement` / `UIAccessibility.post` | Live regions (`liveRegion` semantics) |
